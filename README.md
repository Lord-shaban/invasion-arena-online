# Invasion Arena Online

نسخة متصفح جماعية للعبة **إنفيجن | الحرب الأهلية**. الواجهة عربية RTL، والخادم يحتفظ بحالة المباراة والبطاقات المخفية ويُنفّذ الأوامر داخل غرفة SQLite Durable Object.

## التشغيل

يتطلب Node.js 20.19 أو أحدث.

```bash
npm install
npm run dev
```

يفتح Vite واجهة التطوير وWorker محليًا. لإنشاء نسخة الإنتاج والتحقق من أنواع TypeScript:

```bash
npm run check
npm run build
```

## اللعب

1. أنشئ غرفة وشارك رمزها مع 1–4 لاعبين. لا يلزم حساب؛ مفتاح إعادة الاتصال يُحفظ محليًا في المتصفح.
2. يبدأ المضيف المباراة بعد انضمام لاعب ثانٍ على الأقل. يحصل الجميع على قائدين مختلفين، و5 بطاقات، و6,000 صحة. يختار الخادم اللاعب الأول عشوائيًا.
3. يتكون الدور من السحب، والرئيسية، والمعركة، ونهاية الدور. السحب تلقائي عند إنهاء مرحلة السحب. الحد المعتاد لليد 5 بطاقات.
4. انشر الموارد في الرئيسية لدفع تكاليف القادة. مهارة كل قائد تستخدم مرة واحدة. في المعركة، العب الهجمات والأحداث والدعم؛ الهجوم يفتح استجابة للهدف.
5. الدفاع العام يمتص الضرر حسب متانته، والدفاعات الخاصة توقف نوع الهجوم المطابق. اللاعب الذي يصل إلى صفر يُقصى، وآخر لاعب حي يفوز.

تبدأ المباراة في المرحلة 1 مع حدث الإنزال الجوي. يتقدم المسار مرحلة بعد كل جولة كاملة: السوق السوداء، ثم الهدنة، ثم تعطيل الدفاع، ثم الأرض المحروقة. تفاصيل التكوين والتوقيت في [وثيقة التصميم](docs/superpowers/specs/2026-11-09-invasion-arena-online-design.md).

اللعبة تستخدم القواعد المؤقتة المعتمدة `ruleset-v1`، بما فيها 2–5 لاعبين، و71 بطاقة في الحزمة المشتركة، وخمسة أحداث مراحل. مصدر بيانات البطاقات هو موقع Arena OS الأصلي.

## نطاق النسخة الحالية

- الهجمات المباشرة والخاصة، الهجوم المطور، الدفاع العام والخاص، دعم السحب، الأحداث، مهارات القادة، وإعادة خلط المقبرة عند نفاد الحزمة.
- دعم الحليف العسكري للهجمات المباشرة يتطلب موافقة الحليف واختياره بطاقة دعم. لا يُدمج الهجوم المطور مع هجوم الحليف.
- لا يوجد مؤقت للدور. اللاعب المنقطع يحتفظ بدوره، ويمكنه إعادة الاتصال من نفس المتصفح.
- بعض تفسيرات الكتيب تحتاج مراجعة ضد النسخة المطبوعة. التزمنا بالافتراضات في وثيقة `ruleset-v1`؛ لم نضف حسابات أو سوقًا عامًا أو مؤثرات صوتية.

## النشر على Workers

المشروع يستخدم Workers وSQLite Durable Objects وWebSocket Hibernation. تسجيل الدخول إلى حساب Cloudflare مجاني مطلوب للنشر:

```bash
npx wrangler login
npm run deploy
```

طلبات الملفات الثابتة مجانية وغير محدودة. على الخطة المجانية، حد Workers هو 100,000 طلب يوميًا؛ وحد Durable Objects هو 100,000 طلب و13,000 GB-s يوميًا، مع 5 ملايين قراءة صف و100,000 كتابة صف يوميًا و5 GB بيانات SQLite إجمالًا. تجاوز أي حصة مجانية قد يوقف النوع المتجاوز حتى إعادة ضبط الحصة؛ التطبيق لا يرقّي الحساب تلقائيًا إلى خطة مدفوعة. راجع [حدود Workers](https://developers.cloudflare.com/workers/platform/limits/)، [تسعير Durable Objects](https://developers.cloudflare.com/durable-objects/platform/pricing/)، و[فوترة الملفات الثابتة](https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/).

المشروع مستقل؛ لا تعدّل به ملفات الموقع المرجعي.

ملاحظة: نسخة البداية تدعم دعم الحليف للهجوم المباشر فقط. تجميع الدفاعات عبر الحليف، ومضاعفة تأثير الهجوم غير الضرري بالهجوم المطور، يحتاجان ضبطًا أدق للقواعد قبل تفعيلهما.

عند غياب صورة بطاقة محلية، تعرض الواجهة صورة البطاقة من أصول الريبو المرجعي العام.
